# @coursekit/toolbox

Les fiches de la boîte à outils fournies avec la bibliothèque : de courtes leçons sur les outils
mathématiques dont les cours ont besoin (vecteurs, produit scalaire, pente, énergie, méthode de
Newton, systèmes, nombres à virgule flottante), chacune avec un schéma interactif et deux
questions de vérification.

- `MATH_CAPSULES` : toutes les fiches ;
- `pickCapsules('T4', ['T6', 'à quoi elle sert dans ce cours'])` : celles qu’un cours retient,
  en précisant au besoin où il les utilise ;
- `TOOL_DIAGRAMS` : leurs schémas, que le lecteur et le vérificateur connaissent d’office.

Ce paquet est du contenu ; `@coursekit/diagrams` ne contient que les primitives de dessin.
