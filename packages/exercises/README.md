# @coursekit/exercises

Les exercices de l’atelier (calcul guidé, classement, mise en ordre, code) et leurs
vérifications. Sans DOM : le lecteur les affiche, `coursekit check` prouve que chaque solution
est acceptée et chaque point de départ refusé.

```ts
import { choiceQ, type Exercise, type WorkshopConfig } from '@coursekit/exercises';
```

Voir [docs/ecrire-un-cours.md](../../docs/ecrire-un-cours.md#8-latelier).
