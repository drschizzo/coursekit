# La chute d’un objet (cours jouet)

Un cours minimal qui utilise chaque élément du format au moins une fois : étapes, schéma, scène,
question posée avant l’explication, questions, expérience, explication écrite, exercices des
quatre types, assemblage, cas clinique, test final. Il sert de test d’intégration et d’exemple
court.

```bash
npm run dev:demo      # depuis la racine du dépôt, http://localhost:5181
npm run check -w courses/demo-mini
```
